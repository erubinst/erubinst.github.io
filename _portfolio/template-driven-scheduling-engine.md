title: "Template-Driven Scheduling Engine"
order: 1
excerpt: >-
  A scheduling engine that instantiates task templates onto per-agent/resource timelines and enforces temporal feasibility via Simple Temporal Network (STN) constraint propagation. Uses heuristic search for initial schedule construction and a conflict-driven repair procedure to locally patch schedules in response to resource failures or downtime, avoiding a full re-solve. Includes a simulator and execution framework that ingests status/failure updates in real time to trigger schedule repair.
