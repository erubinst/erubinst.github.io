title: "Simple Temporal Network (STN) Python Implementation"
excerpt: >-
  An implementation of a Simple Temporal Network (STN), a constraint-based representation for temporal reasoning originally introduced by Dechter, Meiri, and Pearl in ["Temporal constraint networks"](https://doi.org/10.1016/0004-3702(91)90006-6) (1991). This implementation uses an incremental propagation technique from Cesta and Oddi's ["Gaining efficiency and flexibility in the simple temporal problem"](https://ieeexplore.ieee.org/document/555676/) (1996) to efficiently update the network as constraints are added, rather than recomputing all-pairs shortest paths from scratch. Code: [github.com/erubinst/pythonSTN](https://github.com/erubinst/pythonSTN)
